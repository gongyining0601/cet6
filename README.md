# CET6 每日打卡 · 真题练习

零成本、零安装的英语六级真题练习工具，**全量 76 套真题 / 3315 题**（2015-06 至 2026-06），手机电脑都能跑。

## 在线使用

- 手机浏览器打开本仓库的 GitHub Pages 地址
- 安卓/iPhone：浏览器菜单 → 「添加到主屏幕」，像 App 一样全屏使用
- 首次打开会缓存全部题库，之后**除听力音频外可离线刷题**（音频走在线 CDN，Service Worker 不缓存跨源资源）
- 打卡记录默认只存本机浏览器；启用私有同步后会经自建端点在多台设备间合并，详见 `docs\同步部署说明.md`

## 功能

- **今日清单**：每天按「完整单元 + 25–40 分钟」自动生成（听力 / 选词填空 / 信息匹配 / 仔细阅读，周六写作或翻译），完成自动打卡
- **底线模式**：忙的时候记几分钟也保住连击，防弃坑
- **错题本**：做错自动入库，自适应遗忘曲线安排复习，连续答对 5 次出库；「智能复习」一键练最薄弱的前 20 题
- **断点续做**：中途退出草稿自动保存，回来接着答（剩余时间一起保存）
- **考场限时**：每组按真实 CET6 单题标准倒计时（听力 72s/题、选词 60s、匹配/阅读 120s、写作/翻译各 30 分钟），超时标红提示；判分后显示「用时 vs 标准」，统计页有限时达标率与平均每组用时
- **估分**：统计页按已练客观题型的得分率 × 真题计分权重折算 CET6 估算分（满分 710），未练部分按同水平外推；**该值为练习数据的启发式折算，仅供参考，非官方换算表**
- **薄弱点专项练**：考点正确率最低处一键开练（错题优先，每组 ≤6 题），练完正确率当场更新，形成「发现薄弱 → 专项练 → 数据回升」闭环
- **听力播放器**：听力题组页内用 `<audio>` 原生播放自有镜像的单文件 m4a（GitHub Pages 主线路 + jsDelivr 备用，自动切换重试，并在同一会话内复用已探明的可用线路）；同考期第 2/3 套共用第 1 套录音，播放器自动指向源卷，76 套卷听力均可播放；全部线路失败时可一键跳懒笔记原站收听
- **深色模式**：顶栏一键切换深色/浅色（晚自习护眼），偏好自动记住
- **阅读划词高亮**：做阅读/匹配/选词时，在文章里划选文字点「高亮」标黄（荧光笔效果），点已高亮的词取消；高亮随做题组持久化，退出来重进还在
- **错题导出 CSV**：备份页一键导出错题本为 CSV（题号/卷/题型/题干/你的答案/正确答案/考点/错次/下次复习/稳固度），Excel 直接打开做自己的复盘表
- **写译自查**：写作字数体检、翻译踩分词覆盖自查
- **本地多账号**：4 位数字学习编号，每人记录独立
- **跨设备同步（可选）**：配置私有端点后，手机与电脑按「项目 + 编号」自动合并记录，清理浏览器数据也能恢复；未配置时同步层完全不激活、不联网

## 题库

- 76 套真题：26 个考期（含 2020-07、2020-09、2022-09、2023-03 等特殊考期），完整卷每套 55 题，第三套 30 题（仅选词/匹配/阅读，听力排期取自第一、二套），6 套纯共用卷（仅写作/翻译独立）
- 写作/翻译题面按日期在全部套卷间轮换
- 来源：懒笔记免费公开真题，转录经双通道交叉自检，76 套全部零问题

## 数据说明

打卡记录的工作副本是**当前浏览器的本地存储**（按学习编号隔离，存储键 `cet6_p1_state_v1_*` 与四级应用互不干扰）。

- **未配置同步**：记录只在本机。换设备请在「备份」页导出 JSON 再导入；清理浏览器数据前务必先导出。
- **已配置私有同步**：每次保存会节流推送一份权威副本到自建端点（`cet6` 命名空间），启动时先拉远端、字段级合并再渲染。清浏览器数据或换设备都能自动恢复。
- 「备份 → 跨设备同步」卡片会显示**未启用 / 已同步 / 同步失败**，不要把「未启用」误当成已经云端备份。

同步内核 `sync.js` 与 CET4 共用同一份文件，治理约定见 `docs\双项目治理说明.md`。

## 本地开发版

本地双击 `index.html` 同样可用（`file://` 协议下不启用 Service Worker）。CSP 已改为静态 meta，对 `file://` 与 https 同时生效。测试与验收记录见本地 `scripts\` 与 `docs\`。
