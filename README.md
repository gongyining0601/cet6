# CET6 每日打卡 · 真题练习

零成本、零安装的英语六级真题练习工具，**全量 76 套真题 / 3315 题**（2015-06 至 2026-06），手机电脑都能跑。

## 在线使用

- 手机浏览器打开本仓库的 GitHub Pages 地址
- 安卓/iPhone：浏览器菜单 → 「添加到主屏幕」，像 App 一样全屏使用
- 首次打开会缓存全部题库，之后**可离线刷题**；打卡记录保存在本机浏览器里，不经过任何服务器

## 功能

- **今日清单**：每天按「完整单元 + 25–40 分钟」自动生成（听力 / 选词填空 / 信息匹配 / 仔细阅读，周六写作或翻译），完成自动打卡
- **底线模式**：忙的时候记几分钟也保住连击，防弃坑
- **错题本**：做错自动入库，自适应遗忘曲线安排复习，连续答对 5 次出库；「智能复习」一键练最薄弱的前 20 题
- **断点续做**：中途退出草稿自动保存，回来接着答（剩余时间一起保存）
- **考场限时**：每组按真实 CET6 单题标准倒计时（听力 72s/题、选词 60s、匹配/阅读 120s、写作/翻译各 30 分钟），超时标红提示；判分后显示「用时 vs 标准」，统计页有限时达标率与平均每组用时
- **估分**：统计页按已练客观题型的得分率 × 真题计分权重折算 CET6 估算分（满分 710），未练部分按同水平外推
- **薄弱点专项练**：考点正确率最低处一键开练（错题优先，每组 ≤6 题），练完正确率当场更新，形成「发现薄弱 → 专项练 → 数据回升」闭环
- **听力播放器**：听力题组页内直接播放（内嵌懒笔记听力专项页），不用再开新标签页
- **写译自查**：写作字数体检、翻译踩分词覆盖自查
- **本地多账号**：4 位数字学习编号，每人记录独立

## 题库

- 76 套真题：25 个考期（含 2020-07、2020-09、2022-09、2023-03 等特殊考期），完整卷每套 55 题，第三套 30 题（听力共用），6 套纯共用卷（仅写作/翻译独立）
- 写作/翻译题面按日期在全部套卷间轮换
- 来源：懒笔记免费公开真题，转录经双通道交叉自检，76 套全部零问题

## 数据说明

打卡记录只保存在**当前浏览器的本地存储**中（按学习编号隔离）。换设备请在「备份」页导出 JSON，再到新设备导入。清理浏览器数据前务必先导出。

## 本地开发版

本地双击 `index.html` 同样可用（`file://` 协议下不启用 Service Worker）。测试与验收记录见本地 `scripts\` 与 `docs\`。
